# HI5033 Database Design

This repository provides supplementary tutorial resources, PostgreSQL
examples and SQL practice activities for HI5033 Database Design.

## Main technologies

- PostgreSQL
- DBeaver Community
- SQL

## Weekly topics

1. Database systems concepts and architecture
2. Data modelling
3. The relational model
4. Basic SQL
5. Advanced SQL
6. Database design
7. Normalisation
8. Database programming
9. Database security
10. Database engines and services
11. Distributed databases and NoSQL systems
12. Database administration

## Getting started

Before commencing the practical activities:

1. Install PostgreSQL.
2. Install DBeaver Community.
3. Connect DBeaver to the local PostgreSQL server.
4. Run `SELECT version();` to verify the connection.
